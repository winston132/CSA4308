# Experiment 36B: BookHaven Online Bookstore Platform

## 1. Overview
BookHaven is a modern literary bookstore featuring categorized book collections, literary synopsis breakdowns, reader review scores, and an integrated shopping basket.

## 2. Core Functional Requirements
- **Literary Catalog Browsing**: Categorized showcase of classical fiction, astronomy, philosophy, and biological treatises.
- **Pricing & Rating Metrics**: Transparent price points and verified reader review score indicators.
- **Cart Management**: Dynamic basket tally tracking selected volume quantities and running invoice totals.
- **Checkout Dispatcher**: Seamless checkout simulation and order confirmation.

## 3. Technology Stack
- HTML5 Semantic Architecture & Serif Typography (`Playfair Display`)
- Responsive CSS3 Grid Structure
- Client-Side Cart Accumulator
