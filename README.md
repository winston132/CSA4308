# CSA4308 - Internet Programming Laboratory

Comprehensive repository containing full-stack implementations, interactive web applications, technical documentations, source code comments, and visual verification artifacts for all **46 laboratory experiments** defined in the Internet Programming curriculum.

## 🚀 Repository Highlights
- **Complete Curriculum Coverage**: All 46 experiments implemented according to exact role-based functional specifications.
- **Verified Execution Artifacts**: Every experiment includes dual visual verification artifacts:
  1. **Output Screenshot** (screenshot.png): High-resolution browser rendering of the executed application.
  2. **Code Execution Screenshot** (code_screenshot.png): Formatted IDE capture of the executed source code.
- **In-Code Output Comments**: Every experiment index.html contains execution output logs, component status records, and screenshot references directly within the source comments.
- **Role-Based Access Control**: Fully functional portals covering Admin, Student, User, Doctor, Inspector, Vendor, and Candidate workflows.
