# CSA4308 - Internet Programming Laboratory

Comprehensive repository containing full-stack implementations, interactive web applications, technical documentations, and output visual verifications for all **46 laboratory experiments** defined in the Internet Programming curriculum.

## 🚀 Repository Highlights
- **Complete Curriculum Coverage**: All 46 experiments implemented from scratch according to exact role-based functional specifications.
- **Modern Frontend Architecture**: Pure semantic HTML5, modern CSS3 variables/grids/flexbox, and interactive vanilla JavaScript without external framework dependencies.
- **Verified Visual Artifacts**: Real, automated headless Chrome rendering screenshots captured and embedded into each experiment output area.
- **Role-Based Access Control**: Portals include authenticated Admin, User/Customer, Vendor, Doctor, Inspector, and Candidate perspectives.
